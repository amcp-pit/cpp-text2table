# Преобразование текста в таблицу

В файле содержится некоторый текст, разбитый на строки. В каждой строке не более 100 слов. Под словом будем понимать набор символов, разделенных пробелами. Например, в строке:
```
To be, or not to be, that is the question:
```
содержится 10 слов:

1. `To`
2. `be,`
3. `or`
4. `not`
5. `to`
6. `be,`
7. `that`
8. `is`
9. `the`
10. `question:`

Необходимо расставить минимальное количество пробелов между словами так, чтобы получился текст по столбцам, выравненный по левому краю. 
При этом столбцы должны отделяться пробелом, а после последнего элемента таблицы в каждой строке пробелов быть не должно. Например, если исходный текст был:
```
one two three four five 
six seventh eight 
nine ten eleven twelve 
1 - 2 - 3 -
```
то после преобразования должен получиться текст:
```
one  two     three  four   five 
six  seventh eight
nine ten     eleven twelve 
1    -       2      -      3    -
```

Результат необходимо записать в файл.

Имена входного и выходного файлов заданы в командной строке. 

## Требования

Программа не должна использовать контейнеры STL (std::vector, std::string и т. д.).
